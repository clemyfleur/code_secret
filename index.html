Comment jouer

  1. Choisissez quatre couleurs, de gauche à droite. Une couleur peut se répéter.
  2. Validez votre proposition et consultez les deux indices.
  3. Ajustez votre code jusqu’à trouver les quatre bonnes positions.

Bien placées : bonne couleur, bonne position.

Mal placées : bonne couleur, autre position.

Les indices sont des totaux : ils ne désignent aucun pion. Chaque occurrence compte une seule fois.

    À EMPORTER

    Code secret sur votre écran d’accueil

    Gardez le jeu à portée de main sur téléphone ou ordinateur, avec son icône à quatre couleurs.

    Choisissez votre appareil ci-dessous pour installer le jeu.

    iPhone ou iPad · Safari

    Ouvrez cette page dans Safari. Dans le menu du navigateur, touchez Partager, puis Sur l’écran d’accueil. Si proposé, activez « Ouvrir comme app web », puis touchez Ajouter.

    Android · Chrome ou navigateur compatible

    Touchez Installer Code secret si ce bouton apparaît. Sinon, ouvrez le menu ⋮ du navigateur et choisissez Installer l’application ou Ajouter à l’écran d’accueil, puis confirmez.

    Ordinateur · Chrome, Edge ou Safari

    Dans Chrome ou Edge, utilisez l’icône d’installation dans la barre d’adresse, le bouton ci-dessus ou la commande d’installation du menu. Sur Mac avec Safari compatible, choisissez Fichier → Ajouter au Dock. Si aucune commande n’est proposée, vous pouvez continuer à jouer dans le navigateur.

    Les intitulés varient selon votre appareil. Si le lien s’ouvre dans une application de messagerie, ouvrez-le dans Safari ou Chrome pour retrouver les commandes d’installation.

    Une première ouverture avec Internet est nécessaire pour préparer le jeu hors connexion. Recharger ou rouvrir démarre une nouvelle partie.
