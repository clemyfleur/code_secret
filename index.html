Comment jouer

  1. Choisissez quatre couleurs, de gauche à droite. Une couleur peut se répéter.
  2. Validez votre proposition et consultez les deux indices.
  3. Ajustez votre code jusqu’à trouver les quatre bonnes positions.

Bien placées : bonne couleur, bonne position.

Mal placées : bonne couleur, autre position.

Les indices sont des totaux : ils ne désignent aucun pion. Chaque occurrence compte une seule fois.
